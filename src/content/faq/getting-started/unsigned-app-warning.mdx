Pits n' Giggles is free and open-source, distributed directly from GitHub rather than through the Microsoft Store or Mac App Store, so Windows and Mac may show a security warning the first time you run it. This is common for indie/open-source apps and doesn't mean the app is unsafe.

**Windows:** the Windows EXE is code signed, starting with the first release after the production certificate is issued. Free code signing provided by SignPath.io, certificate by SignPath Foundation. Older releases are unsigned and will always show the warning. Even for signed releases, SmartScreen builds up trust in a file over time, so you may still see the prompt on a new release for a while.

**macOS:** builds are not signed, so Gatekeeper will warn you.

**Check your download:** right-click the EXE, choose Properties, then **Digital Signatures**. The signer should be *SignPath Foundation*. You can also compare the file's SHA256 against `checksums.txt` on the same GitHub release. See the [Code Signing Policy](/code-signing) for details.

<PlatformTabs platforms={["windows", "macos"]}>
  <PlatformPanel platform="windows">

When you double-click the executable, you'll see a blue **"Windows protected your PC"** dialog from Microsoft Defender SmartScreen.

1. Click **More info**
2. Click **Run anyway**

You only need to do this once per downloaded version - subsequent launches of the same file won't show the prompt again.

  </PlatformPanel>
  <PlatformPanel platform="macos">

If you double-click the app and see a message saying it **"cannot be opened because it is from an unidentified developer"** (or "Apple could not verify..."):

1. Click **Cancel**
2. Open **System Settings** → **Privacy & Security**, scroll to the **Security** section, and you'll see a message about the app being blocked
3. Click **Open Anyway**, then confirm **Open** in the dialog that appears

Alternatively, **right-click (or Control-click) the app → Open**, then confirm **Open** in the dialog - this bypasses Gatekeeper without needing to visit System Settings.
